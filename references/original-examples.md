## 使用方法

1. 按当前文稿的意思选择接近的动作关系：加工、编排、连接、裁切、重复等。不是每个主题都需要机器、人物或胶片。
2. 用图像查看工具检查完成构图；用本地 FFmpeg 抽取第 0、10、20、30、49 帧组成总览，检查组装顺序。这四个文件均为 50 帧、5 秒的 10fps GIF。
3. 保留黑白印刷剪贴、彩色纸张点色、强色场、裁切边与克制投影。注意主要物件互相作用，避免只有几个互不相关的图标依次弹出。
4. 原 GitHub 文件可直接作为首选 reference，不要求先做自己的参考。文稿语义匹配时可以直接沿用样片的构图、物件组合、配色、叙事结构和动作顺序，不必为了原创而换掉有效设计；只调整语义不符的部分。将具体借用项写进画面脚本，保留来源及许可。示例人物不能被当成用户本人；通用人物仍按人物规则确认。原 GIF 的直接复用或剪辑须如实标为原版素材，不能声称为新生成结果。
5. 原 GIF 仅 240×427，适合作为风格与动作参考；其低分辨率、10fps 和部分边缘提前露出不是交付标准。新成片沿用当前项目的画幅、帧率、确认静帧及首帧约定。
6. 本版本用分层代码实现可控的组装动作。参考片来自原版生成流程，不能承诺逐像素复现模型生成的运动或复杂手部形变。
