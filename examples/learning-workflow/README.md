# 学习流程：四列审阅示例

以下文案是公开演示用的概括表达。图片与视频来自本项目已完成的真实制作；没有提供原口播视频，因此没有真实源片时间码。

| 文案 | 时间/时长 | 预期画面呈现 | 最终结果图 |
|---|---|---|---|
| 学习分成搭地图、做案例和内化三个步骤。 | 待对齐；演示 6 秒 | 地图、案例档案、脑与齿轮依次落位，纸带连接成三步路径。 | ![三步学习路径](01-three-steps.png) |
| 信息过多、难以判断取舍，容易把学习范围铺得过大。 | 待对齐；演示 7 秒 | 资料进入，选择框反复切换，地图和资料逐渐向四周摊开。 | ![资料摊开](02-information-sprawl.png) |
| 用 AI 帮助拆解各阶段的学习目标和范围。 | 待对齐；演示 9 秒 | 散乱资料进入整理机器，逐张输出带目标和边界的阶段任务卡。 | ![整理与输出](03-stage-plan.png) |

[播放或下载连续样片](preview-22s.mp4)：22 秒、528 帧、720×1280、24fps、H.264、无声。章节为 0–6、6–13、13–22 秒，仅指本预览内部位置。

制作方式：内置图片生成提供半调地图、案例资料、脑与齿轮、橙色漏斗机器；本地 Canvas 组合独立图层并准确排字；Chrome 渲染、FFmpeg 编码。第三镜借用了上游紫色参考的输入—加工—输出构图。最终构图经确认后实现过程，重新渲染完成帧与批准图逐字节一致；成片完整解码通过。
